ESP32 LED 点阵屏

发表于2025|更新于2026-09-04
浏览量:评论数:

复刻自 B 站浪迹天涯的鸟的开源项目：用一块 ESP32 驱动 16×16 的 WS2812 灯板，做成一套"算法驱动"的实时效果引擎。主打重力感应水波（MPU6050 实时驱动，倾斜灯板水就跟着流）与 DOOM 风格跳火花，多帧率可调、效果可扩展。打板文件、购置清单、焊接接线说明与固件源码全部公开，从热台焊接、烧录固件到上电点亮可完整跟做。

上手步骤

  • 嘉立创免费打板（每月两次），板文件在嘉立创工程或 Hardware 文件夹直接下载
  • 热台 + 烙铁焊接（器件较小，需要耐心），MPU6050 用胶贴到灯板背面
  • 编译烧录 Firmware 固件，按 Hardware 文档接线，上电即亮

硬件构成

  • 主控：ESP32 开发板 ×1
  • 灯板：16×16 WS2812B（3332 封装，256 像素）×1
  • 传感器：MPU6050 六轴 ×1
  • 供电：5V 电源模块（点亮全屏约需 5A 以上）

功能亮点

  • 重力感应水波：MPU6050 驱动，灯板倾斜即响应
  • DOOM 火花：算法模拟火苗跳动
  • 蛇形走位映射：WS2812 串行布线自适应（SERPENTINE）
  • 一键切换：IO0 按键长按切效果、短按切颜色
  • 性能加速：可选 esp_dsps 加速版本，另有 without_dsps 版对照

文档与工具

购置清单（docs/）、打板文件（hardware/）、固件源码（firmware/，含 water_sim / doom_fire / sim_manager / BSP 驱动）、接线图、test.c 灯板检测程序。
